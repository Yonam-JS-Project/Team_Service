1. Create Trip (여행 생성)

POST /api/trips - 새로운 여행을 생성합니다

2. Get Trip Details (여행 상세 조회)

GET /api/trips/:shareCode - 특정 여행의 전체 정보를 조회합니다

3. Get Trip Summary (여행 요약 조회)

GET /api/trips/:shareCode/details - 여행 요약 정보를 조회합니다

4. Update Trip (여행 수정)

PUT /api/trips/:shareCode - 여행 정보를 수정합니다

5. Delete Trip (여행 삭제)

DELETE /api/trips/:shareCode - 여행을 삭제합니다

6. Toggle Checklist (체크리스트 토글)

PUT /api/checklist/:placeId - 장소의 완료 상태를 토글합니다

7. Get All Public Images (전체 공개 이미지 조회)

GET /api/album - 모든 공개 이미지를 조회합니다

8. Get Album Images (앨범 이미지 조회)

GET /api/album/:shareCode - 특정 여행의 앨범 이미지를 조회합니다

9. Upload Album Images (이미지 업로드)

POST /api/album/:shareCode - 앨범에 이미지를 업로드합니다

10. Delete Album Image (이미지 삭제)

DELETE /api/album/:imageId - 앨범 이미지를 삭제합니다
